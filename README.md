# Tic-Tac-Toe

A single-file, browser-based tic-tac-toe game. Open `index.html` in any browser — no build step or server needed.

- Play against the computer (Easy or Unbeatable minimax AI) or a friend on the same device
- Running score with draws; the starting player alternates each round
- Keyboard play: keys 1–9 in numpad layout, `N` for a new round
- Light and dark themes follow your system setting
