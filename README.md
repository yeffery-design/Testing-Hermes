# Browser Games

Single-file games that run in any browser. Open the HTML file directly; there's no build step or server.

## Tic-Tac-Toe (`index.html`)

- Play against the computer (Easy or Unbeatable minimax AI) or a friend on the same device
- Running score with draws; the starting player alternates each round
- Keyboard play: keys 1–9 in numpad layout, `N` for a new round
- Light and dark themes follow your system setting

## Ludo (`ludo.html`)

- 2–4 players; each seat (Red, Green, Yellow, Blue) can be a human, the computer, or empty
- Classic rules: roll a 6 to leave the yard, a 6, capture or token reaching home earns another roll,
  three 6s in a row forfeits the turn, start squares and stars are safe, exact roll needed to finish
- Tokens step square by square; stacked tokens fan out on shared squares
- Keyboard: Space rolls, Tab cycles through playable tokens, Enter moves one
